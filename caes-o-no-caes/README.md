# ¿Caés o no caés? · Detective Digital

Juego educativo interactivo para jóvenes de Catamarca. Ayuda a reconocer señales de posibles estafas digitales y practicar decisiones seguras.

## Cómo jugar

Abrí [index.html](./index.html) en el navegador. No necesita instalar dependencias, tener una cuenta ni enviar información personal.

- 5 casos ficticios: cambio de número, premio trampa, oferta imposible, código secreto y voz imitada.
- 15 pistas para investigar, 500 puntos de experiencia posibles y explicaciones de cada decisión.
- Tarjeta de resultado descargable en PNG.
- Diseño adaptable a celulares, tablets y computadoras.

## Archivos

- `index.html`: estructura de la experiencia.
- `styles.css`: interfaz y animaciones.
- `app.js`: desafíos, puntuación y funcionamiento.

## Seguridad

Todos los mensajes son simulados. No se solicitan datos personales, códigos, contraseñas ni dinero. Las recomendaciones remiten a organismos públicos, como el BCRA y Argentina.gob.ar. Las situaciones presentadas no constituyen asesoramiento legal ni financiero.
